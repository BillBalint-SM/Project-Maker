# Domain Docs

Before using Project, Customer, operator, organization, tenant, mailbox, or
correspondence language, read:

- Root `CONTEXT.md`.
- Relevant ADRs in `docs/adr/`.

Use the glossary’s ownership distinctions in issue titles, proposals,
hypotheses, tests, configuration, and operations documentation. `Customer`
always means the external Project Customer; infrastructure belongs to the
Operator organization. Surface any conflict with an ADR explicitly.

This repository uses one domain context. Do not create `CONTEXT-MAP.md` or context-local domain documentation unless a real multi-context need emerges.
