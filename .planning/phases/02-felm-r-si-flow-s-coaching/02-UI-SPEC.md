### Mantine téma-beállítás (a spacing/typography/color kontraktus kikényszerítéséhez)

A Mantine alap spacing-skálája (xs–xl, rem-alapú) NEM egyezik a lenti 8-pontos px-skálával — ezért a `createTheme()` hívásban explicit felül kell írni. Ez a `src/main.tsx`-ben a `MantineProvider` mellé kerülő tervezői/végrehajtói feladat, nem opcionális:

```tsx
// src/main.tsx (kiegészítés — Mantine 9 bevezetése, 02-RESEARCH.md Code Examples szerint)
import "@mantine/core/styles.css";
import { MantineProvider, createTheme } from "@mantine/core";

const theme = createTheme({
  fontFamily: "Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif",
  primaryColor: "brandTeal",
  colors: {
    // 10-árnyalatú Mantine-paletta, a meglévő --primary (#126b68) köré generálva
    brandTeal: [
      "#e6f5f4", "#c7e6e3", "#a3d6d1", "#7ec5bf", "#5fb5ad",
      "#126b68", "#0f5653", "#0c4341", "#093230", "#062221"
    ]
  },
  spacing: { xs: "4px", sm: "8px", md: "16px", lg: "24px", xl: "32px" },
  fontSizes: { xs: "14px", sm: "14px", md: "16px", lg: "20px", xl: "28px" },
  defaultRadius: "8px" // konzisztens a legacy --line/8px border-radius mintával
});

createRoot(document.getElementById("root")!).render(
  <MantineProvider theme={theme}>
    <RouterProvider router={router} />
  </MantineProvider>
);
```

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Ikon-gap-ek, badge belső padding, `checklist-index` kör belső margó |
| sm | 8px | Kompakt elem-távolság (form mező label→input, Accordion header belső gap) |
| md | 16px | Alapértelmezett elem-távolság (kártya belső padding, form-grid gap) |
| lg | 24px | Szekció padding (Cockpit-panel, Döntés-panel, form-section padding) |
| xl | 32px | Layout-gap-ek (fülek közötti fő tartalom-terület margó, oldal fejléc alatt) |
| 2xl | 48px | Nagy szekcióhatárok (Cockpit → Checklist scroll-célpont fókusz-margó, D-08 `fixGap`) |
| 3xl | 64px | Oldal-szintű térköz (üres állapot vertikális középre-igazítás felső/alsó margója) |

Exceptions:
- **Ikon-only gombok (`ActionIcon`) érintési célmérete 44×44px**, nem 42px (a legacy `.icon-button` 42px-es mintájától eltérően) — projektlista sor-akciók (archiválás/törlés ikon) és a checklist-kártya "mind nyit/zár" ikon-gombja erre a méretre kerül, akadálymentességi minimumként.
- Az Accordion `Control` és `Panel` belső paddingje Mantine alapértelmezett komponens-belső érték marad (nem 8-pontos kényszer) — ez komponens-belső tér, nem layout-gap; a tervező/végrehajtó ne hangolja kézzel.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 600 (semibold) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.2 |

Pontosan 4 méret (14/16/20/28) és pontosan 2 súly (400/600) deklarálva — a Mantine `fontSizes` skála (fenti `createTheme`) ezt tükrözi.

- **Body (16/400/1.5):** checklist-kártya kérdés-szövege, coaching-panel 4 rovatának szövege (miért/mit/hogyan/etikett), form-mező input-szöveg, hint/segédszöveg.
- **Label (14/600/1.4):** mező-címkék, kategória-badge-ek, státusz-badge-ek, `field span` feliratok, Accordion `Control` kategórianév.
- **Heading (20/600/1.2):** szekció-címek (Cockpit "Hiányosságok", Döntés-panel alcímei), Tabs aktív fül felirata, Modal cím.
- **Display (28/600/1.2):** oldal-cím (projektlista `h1`, projekt-név a `detail-header`-ben, Döntés-panel `decision-copy h2` nagy címe).

Forrás: a legacy `styles.css` jelenleg 6+ ad hoc méretet használ (0.7rem–3rem clamp) — ez a fázis TUDATOSAN szűkíti 4 méretre/2 súlyra a Mantine-bevezetéssel egyidejűleg, a design-kontraktus 6-dimenziós ellenőrzésének megfelelően.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#eef2f6` (+ `linear-gradient(180deg, #f5f7fb 0%, #eef2f6 36%, #e7edf4 100%)`) | Oldal-háttér (body), fülek közötti üres terület — forrás: `src/styles.css:2,34-35`, megtartva. |
| Secondary (30%) | `#ffffff` (`--surface`) | Kártya-/panel-háttér: checklist-kártya (kibontva), Cockpit-panel, Döntés-panel, Modal, projektlista táblázat sorai. |
| Accent (10%) | `#126b68` (`--primary`) | KIZÁRÓLAG: elsődleges CTA-gombok (Új projekt létrehozása, Mentés, playbook-kiválasztó modál megerősítő gombja), aktív Tab jelző/háttér, Accordion aktív `Control` szegély/háttér, completion/readiness `Progress`-sáv kitöltése, fókusz-gyűrű (`focus-visible` outline), coaching-panel rovat-címkék ikon-színe. |
| Destructive | `#b42318` (`--danger`) | KIZÁRÓLAG: Törlés-gomb (projekt véglegesítő törlése), törlés-megerősítő Modal szövege/gombja, "kritikus" súlyosságú gap-badge (Cockpit gap-lista). |

Accent reserved for: elsődleges CTA-gombok, aktív navigációs állapot (Tab/Accordion), haladás-/pontszám-sávok kitöltése, fókusz-jelzés. **Soha** nem használható díszítő elemként, ikon-alapszínként vagy másodlagos gombokon.

**Meglévő szemantikus státusz-színek megtartva** (nem sértik a 60/30/10 elvet — funkcionális állapotjelzők, nem dekoráció): `--amber` (#9a5b00, "becslés alatt"/figyelmeztetés), `--blue` (#255ca8, "előkészítés" info-állapot), `--green` (#257247, "kész"/siker-állapot). Forrás: `src/styles.css:16-20`, a legacy `status-badge`/`completion-badge` minta 1:1 folytatódik Mantine `Badge` `color` propon keresztül.

| Error state | **Mentési hiba:** "A mentés nem sikerült. A legutóbbi változtatásaid egyelőre nincsenek elmentve — próbáld újra." · **Betöltési hiba:** "A projekt betöltése nem sikerült. Frissítsd az oldalt, vagy térj vissza a projektlistához." |

**Playbook-választás copy (SURVEY-04, projekt-létrehozó Modal):** mező-címke: "Playbook" · az egyetlen jelenleg elérhető opció felirata: "Általános (30 tételes checklist)" · segédszöveg a mező alatt: "A playbook a létrehozás után nem módosítható." (D-03 kikényszerítése a felhasználó felé, nem csak a UI-logikában.)
